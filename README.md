# Linux Server Performance Stats (`server-stats.sh`)

A lightweight Bash script designed to analyze and monitor essential Linux server performance statistics, including CPU, Memory, Disk usage, and top resource-consuming processes.

## 🚀 Features
- **CPU Usage:** Calculates total CPU utilization percentage.
- **Memory Usage:** Displays total, used, and free memory along with the precise usage percentage.
- **Disk Usage:** Monitors total, used, and free disk space across the filesystem.
- **Top Processes:** Identifies the top 5 processes consuming the most CPU and Memory resources.

---

## 🛠️ Prerequisites
- Linux environment (Ubuntu / WSL2)
- Bash shell
